# 05 — Реестр SEO-рисков HaierShop.uz

**Дата:** 19.11.2026.

**Классы риска:**
- **GREEN** — низкий риск при соблюдении инвариантов.
- **YELLOW** — контролируемый риск: анализ, тест, ограниченное внедрение.
- **RED** — высокий риск для текущей видимости. RED-пункты **не входят в план внедрения**; они собраны в §3 как стратегические гипотезы.

Реестр состоит из двух частей:
- **(A)** риски, которые уже реализуются сейчас (текущее состояние);
- **(B)** риски будущих вмешательств — что опасно менять.

## 3. Стратегические гипотезы (RED — не для непосредственного внедрения)
1. **Объединение корня `/` и `/uz`.** Google выбрал `/` вместо объявленного `/uz`. Гипотеза: 301 `/` → `/uz` или наоборот консолидирует сигналы главной. Риск: главная + x-default + hreflang. Нужны данные: клики `/` (112) и `/uz` (43) за 12 мес малы по сравнению с `/ru` (2 157). **Выигрыш не доказан.**
2. **Единый x-default.** Сейчас `/ru` на 714 страницах и `/uz/blog` на 46. Влияние на ранжирование не доказано, Google использует x-default только для несовпадающих языков.
3. **Нормализация URL VRF-товаров** (модель в slug). Возможная польза в модельных запросах против гарантированного риска R-B1. Применять **только к новым товарам**.
4. **Консолидация кластера статей о водонагревателях** (~28 статей). Только после инвентаризации по GSC и только для статей с нулевым трафиком за 12 мес.
5. **Добавление `Sitemap:` в robots.txt.** Формально это правка robots.txt (RED по классификации), фактически риск минимален. Альтернатива без правки robots — проверить отправку обоих sitemap в GSC (действие в GSC — после разрешения владельца).
