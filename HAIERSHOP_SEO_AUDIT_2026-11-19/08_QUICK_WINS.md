# 08 — Quick Wins (только подтверждённые, относительно безопасные)

**Отбор:** каждый пункт подтверждён данными, относится к классу GREEN (или YELLOW с минимальным фактическим риском, это отмечено отдельно) и **не меняет URL, canonical-логику, hreflang и robots.txt**. Внедрение — только после отдельного разрешения. Даже GREEN не гарантирует отсутствия риска: каждое изменение проходит чек-лист из документа 07 (раздел C).

**Сюда намеренно не вошли:**
- **HS-01** (фиктивный рейтинг) и **HS-04** (возврат и доставка в JSON-LD). Это P0, но не «быстрые победы»: это устранение нарушений с компромиссом (пропадут звёзды в выдаче). Они стоят первыми в roadmap (документ 06).
- RED-гипотезы (документ 05, §3).
- Точечные правки, которые **по классификации задания относятся к RED** (canonical, правила индексации), хотя фактический риск у них низкий. Они вынесены в раздел «Ожидают решения владельца» в конце документа.

### QW-2. Заменить «AI-ответ» в meta description (HS-27) — GREEN
- **Проблема:** в сниппет попадает текст «Я проанализировал данные по тепловому насосу Haier HPM08-Nd2… Ниже представлены мои рекомендации… 🇷🇺 Рекомендации по SEO…» (~1 000 символов).
- **Доказательство:** HTML и JSON:API `metatag` для `/ru/teplovye-nasosy/otopitelnoe-oborudovanie/teplovoy-nasos-haier-hpm08-nd2`.
- **Масштаб:** 1 подтверждённый URL (скан всех метатегов и текстов API).
- **Решение:** поставить уже подготовленное описание (оно есть внутри вставленного текста, ~160 символов). Ввести редакторскую проверку AI-текстов перед публикацией.
- **Уверенность:** HIGH.
- **Проверка:** перекраулинг meta description.
- **Откат:** ревизия Drupal.
- **Ожидаемый результат:** профессиональный сниппет. Эффект на CTR — гипотеза (у URL 32 показа за 12 мес).

### QW-3. Исправить ошибки товарных данных (HS-06) — GREEN
- **Проблема:** неверные модели и характеристики.
- **Доказательство** (полный список — `10_AUDIT_EVIDENCE.csv`, HS-06):
  - 10 страниц, где модель в title ≠ H1. Например, `/ru/promyshlennye-kondicionery-vrf-sistemy/kanalnye-vnutrennie-bloki-vrf/kanalnyy-srednenapornyy-4`: H1 AD182MJERAB, title AD282MJERAB.
  - 29 расхождений характеристик UZ↔RU у 16 товаров. Например, AC160S1LK1FA: охлаждение 15 500 против 14 000 Вт; фанкойл FCE-102: 5 580 против 5.58; COZY 208: 24 против 243 мм.
  - UZ-посудомойка с H1 «Kir yuvish mashinasi».
  - UZ-поле модели «17100/21535» у AS18IDHHRA.
- **Масштаб:** ~26 товарных URL.
- **SEO-эффект:** точность сниппетов и модельных запросов, доверие. Устраняется противоречие между языковыми версиями.
- **Решение:** сверить с даташитом Haier и исправить значения. URL не трогать.
- **Уверенность:** HIGH.
- **Проверка:** повторный скрипт сверки (title↔H1↔sku; API UZ↔RU) → 0 расхождений.
- **Откат:** ревизии.
- **Ожидаемый результат:** корректные данные. Рост трафика не гарантируется.

### QW-4. UZ «muzlatgich» → холодильники: синонимы (GREEN) и блок-ссылка (YELLOW) без смены URL (HS-05)
- **Проблема:** по запросам холодильников в UZ Google показывает категорию морозильников.
- **Доказательство** (GSC, 3 мес, `/uz/muzlatgichlar`):

  | Запрос | Показы | Поз. | CTR |
  |---|---|---|---|
  | «muzlatgich narxlari» | 1 140 | 5.5 | 1.6% |
  | «muzlatgich» | 1 062 | 6.3 | 0.7% |
  | «muzlatkich narxlari» | 191 | 6.8 | — |

  SERP «muzlatgich narxi» состоит из холодильников. Спрос (оценка Google Ads): muzlatgich 1 300 / мес против sovutgich 390.
- **Масштаб:** 2 URL (`/uz/muzlatgichlar`, `/uz/sovutgichlar`).
- **SEO-эффект:** перенаправление пользовательского интента на релевантную категорию; вероятный рост CTR и вовлечённости по семейству запросов (~2 800 показов за 3 мес).
- **Решение:**
  - На `/uz/muzlatgichlar` — заметный блок над списком: «Sovutgich (xolodilnik) qidiryapsizmi? → Haier sovutgichlari», со ссылкой на `/uz/sovutgichlar`.
  - В тексте `/uz/sovutgichlar` — естественное использование «muzlatgich» как синонима.
  - **Title/H1 не трогать на этом шаге** (это YELLOW, следующий этап).
- **Уверенность:** HIGH (по проблеме), MEDIUM (по величине эффекта).
- **Проверка:** GSC, 28 дней: показы и CTR по muzlatgich* на `/uz/sovutgichlar` против `/uz/muzlatgichlar` в сравнении с базой.
- **Откат:** удалить блок.
- **Ожидаемый результат:** часть показов и кликов по запросам холодильников переходит на нужную категорию. Объём — гипотеза.

### QW-5. Пустые категории: вывести описание и связанные категории (HS-26) — YELLOW (изменение шаблона и новые ссылки; удалять ничего не нужно)
- **Проблема:** 8 категорий без товаров отдают 200 с ~10 видимыми словами. Описание таксономии при пустом списке не выводится.
- **Доказательство:**
  - `/ru/vstraivaemaya-tekhnika/dukhovki`: 0 товаров; в API описание 345 слов; GSC 12 мес — 70 кликов, 2 584 показа, поз. 13.8;
  - также `/ru/vstraivaemaya-tekhnika/mikrovolnovye-pechi`, `/ru/vitrinnye-kholodilniki`, `/ru/morozilniki/morozilnye-shkafy` и 4 UZ-версии.
- **Масштаб:** 8 URL.
- **SEO-эффект:** снижение риска soft-404 и лучший опыт пользователя.
- **Решение:** шаблон категории выводит описание, даже если товаров нет, плюс блок «Смотрите также» со ссылками на ближайшие заполненные категории. **Не удалять страницы и не ставить noindex** (это RED).
- **Уверенность:** HIGH.
- **Проверка:** URL Inspection без «Soft 404»; вовлечённость в GA4.
- **Откат:** шаблон из git.
- **Ожидаемый результат:** страницы перестают быть пустыми. Трафик — гипотеза.

### QW-7. 301 для мёртвых URL, у которых есть **точный** живой аналог (HS-02, часть) — YELLOW с минимальным фактическим риском
- **Почему здесь:** исходный URL уже отдаёт 404/403, терять нечего. Цель — тот же товар по новому адресу.
- **Доказательство:** строгая классификация 128 мёртвых URL. **Класс A — 31 URL (484 клика за 12 мес): тот же slug жив под новым родителем** (29 товаров и 2 категории фанкойлов). Полная карта со статусами проверки — `13a_REDIRECT_MAP.csv`. Класс B — 9 URL (152 клика): тот же цифровой код, но другой slug, серию нужно проверить вручную. Класс C — 8 URL (100 кликов): только частичное совпадение. Примеры класса A:
  - `/ru/otopitelnoe-oborudovanie/elektricheskiy-kotyol-haier-cozy-208` (84) → `/ru/otopitelnoe-oborudovanie/elektricheskie-kotly/elektricheskiy-kotyol-haier-cozy-208`
  - `/ru/teplovye-nasosy/teplovoy-nasos-haier-hpm10-nd2` (56) → `/ru/teplovye-nasosy/otopitelnoe-oborudovanie/teplovoy-nasos-haier-hpm10-nd2`
  - `/ru/morozilniki/morozilnyy-lar-haier-hce379r` (23) → `/ru/morozilniki/morozilnye-lari/morozilnyy-lar-haier-hce379r`
  
  Полный список с кандидатами — `10_AUDIT_EVIDENCE.csv`, HS-02.
- **Важно:** в quick win входит только класс A. Классы B и C требуют ручной проверки: `proline-232-ti` ↔ `proline-s-232` может оказаться другой серией; `proline-218-ti` даёт два кандидата (Urban S 2.18 и ProLine S 2.18); `es80h-d3` ↔ `es80h-gfdh-yb` — другой товар.
- **Решение:** партия 10 URL класса A с наибольшими кликами → 301 (модуль Redirect или правило nginx; установка модуля — отдельное решение). Наблюдение 14 дней, затем следующая партия.
- **Уверенность:** HIGH (по проблеме), MEDIUM (по совпадению пар до ручной проверки).
- **Проверка:** GET без следования редиректу → 301 → 200; в GSC «Not found (404)» число снижается.
- **Откат:** удалить запись редиректа.
- **Ожидаемый результат:** возврат части исторических кликов на действующие URL. Сколько — гипотеза.

## Ожидают решения владельца: точечные правки RED-класса по типу

По классификации задания изменения canonical и правил индексации относятся к RED, поэтому эти пункты **не входят в quick wins и в план внедрения**. Ниже — доказательства и оценка фактического риска, чтобы владелец мог принять решение. Сводная таблица — документ 06, §2a.

### R-1. Убрать `unavailable_after:2025-03-01` с товара (HS-03) — **RED по типу** (директива индексации), фактический риск низкий
- **Проблема:** живой товар исключён из индекса директивой с датой в прошлом.
- **Доказательство:**
  - `https://haiershop.uz/ru/promyshlennye-kondicionery/kanalnyy-kondicioner-haier-ab71s1lg1fa1u71s1lr1fa-r32` → `<meta name="robots" content="index, follow, unavailable_after:2025-03-01">`;
  - URL Inspection: «Crawled — currently not indexed» (последний краулинг 14.10.2026).
- **Масштаб:** 1 URL (из 760 проверенных).
- **SEO-эффект:** возврат коммерческой страницы в индекс.
- **Решение:** удалить переопределение robots в метатегах этого товара.
- **Уверенность:** HIGH.
- **Проверка:** HTML без `unavailable_after`; через 1–3 недели URL Inspection → «Submitted and indexed».
- **Откат:** вернуть значение метатега (минуты).
- **Ожидаемый результат:** страница снова может получать показы по запросам модели AB71. Гарантий по объёму нет.

По URL Inspection Google canonical игнорирует.
