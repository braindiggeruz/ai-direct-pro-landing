7. ПРОТОКОЛ ПРИЁМКИ
Для каждого пункта: дата / тестовые данные / ожидаемый результат / факт / ответственный.
[ ] Обычная заявка сохранена, менеджер видит согласованные поля.
[ ] Неверный ввод объяснён, предыдущие ответы не потеряны.
[ ] Повтор того же запроса не создаёт новую заявку; новое обращение разрешено отдельно.
[ ] Сетевой сбой не даёт ложного подтверждения.
[ ] При недоступной интеграции понятны статус, ответственное лицо и восстановление.
[ ] Запрос на запись не выдан за подтверждённую бронь.
[ ] Проверены все выбранные языки и переключение между ними.
[ ] Если выбран AI, вопросы без источника передаются человеку.
[ ] Если выбрана оплата, есть отдельная проверка провайдера и статусов.
[ ] Заказчик получил доступы, инструкцию и условия сопровождения.
