# Как подготовить и запустить рассылку

Откройте https://gptbot.uz/admin-tools/lead-radar . В блоке «Отдельный Telegram-аккаунт» настроен TG Sender, отправитель заканчивается на 2410. Сверьте его перед запуском. QR для повторного подключения этого аккаунта не требуется.

1. «Все Telegram-контакты и кампании» → выберите сохранённую аудиторию либо создайте новую и отметьте нужные компании. Прежняя «Общая аудитория» из 28 контактов сохранена.
2. «К сообщению» → «Проверить контакты». Дождитесь результата. Если источник возвращает 429, дождитесь показанного времени; частое повторение проверки не ускорит её.
3. Отредактируйте «Текст кампании». Для автомоек сохранён отдельный текст в новом поиске; для общей аудитории — общий текст о приёме заявок.
4. Для первого делового обращения выберите «Первое обращение на публичный бизнес-контакт». Сверьте компанию, контакт и страницу-источник. Не отмечайте согласие, если его не получали.
5. «Подтвердить источники» → «Подготовить рассылку». Проверьте точные тексты, отправителя и исключённые записи.
6. Только после проверки нажмите «Подтвердить и запустить для N компаний». Pause и Stop находятся в карточке кампании.

Ограничения текущего подключения: текстовые сообщения; до 30 в сутки по UTC; интервал не меньше 120 секунд. Работающий компьютер для серверной отправки не требуется. Подключение и проверка контактов сами по себе ничего не отправляют.

На момент подготовки подтверждённых адресатов для запуска ещё нет. Новый поиск автомоек сохранил 22 карточки, однако источник не указал у них контакты. Это найденные компании, а не готовая база для рассылки. В общей аудитории идёт отдельная проверка контактов; автоматический запуск не включён.
