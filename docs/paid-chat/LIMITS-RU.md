# Лимиты AI-чата и честный 429

Код: `functions/lib/gpt-chat/turn-store.ts` (правила, `reserve`, `explain`, `allowance`), `functions/api/gpt/chat.ts` (ответ 429), тексты — `functions/lib/gpt-chat/chat-copy.ts`. Тесты: `tests/gpt-chat-limits.test.ts`, выбор пакета — `tests/gpt-billing.test.ts`. Решения плана: L3 (у пакета нет часового лимита), L5 (бесплатный счёт по аккаунту и по IP), L18 (гостевой `/api/gpt/account` не ходит в D1).

## Правила

Ход принимается одним `INSERT … SELECT`: решение и резерв атомарны между изолятами. «Израсходован» значит ответ списан (`done`) или ещё готовится (резерв не истёк, 120 с). Сутки — UTC, то есть с 05:00 по Ташкенту.

| Кто | Правило | Причина в 429 | Когда снова можно |
|---|---|---|---|
| Бесплатно | `GPT_FREE_DAILY_LIMIT` (15) за сутки, **и** по аккаунту, **и** по хешу IP, среди ходов без пакета | `daily` | следующие 00:00 UTC |
| Бесплатно | `GPT_FREE_HOURLY_LIMIT` (5) за скользящий час, так же по аккаунту и по IP | `hourly` | через час после 5-го с конца хода в окне |
| Пакет | `PACK_DAILY_LIMIT` = 50 за сутки по аккаунту | `pack_daily` | следующие 00:00 UTC |
| Пакет | `message_limit` (300) на период; период действует | `monthly` | не снимается временем |
| Все | не больше 2 ответов одновременно | `busy` | когда истечёт более ранний резерв (≤ 120 с) |
| Все | запросов с одного хеша IP за час, любых: 100 без пакета, 1000 с пакетом | `ip` | через час после 100-го (1000-го) с конца |

Следствия:
- Вход и выход не дают новой квоты. После входа на том же адресе действует то, что адрес уже потратил как гость. Соседи за одним NAT делят квоту, как и раньше.
- У пакета нет часового лимита (раньше в коде было «20 в час», в правилах пакета его нет).
- Пустой, истёкший или отозванный пакет не блокирует бесплатные ответы. `BillingStore.access()` отдаёт только действующий период с остатком, из нескольких — тот, что кончается раньше. Если пакет кончился между `access()` и резервом (гонка), `reserve` отвечает `monthly`, и чат сразу повторяет ход по бесплатным правилам. Поэтому посетитель `monthly` не получает.
- Если причин несколько, в ответе та, что снимается позже.

## Ответ 429

```json
{"ok":false,"code":"limit_reached","reason":"hourly","tier":"free","remaining":10,
 "limits":{"daily":15,"hourly":5},"retryAt":1790000000000,"retryAfterSec":2400,
 "message":"Лимит бесплатных сообщений в час — 5. Снова написать можно через 40 мин."}
```
- Заголовок `Retry-After` равен `retryAfterSec` (≥ 1).
- `tier` — `free` или `paid`. У пакета `limits` = `{"daily":50,"hourly":null}`, а `remaining` показывает остаток пакета.
- `message` пишется на языке хода (`locale`: `ru` или `uz`) и не содержит названий тарифов и цен. Ошибки провайдера (`no_key`, `rate_limit`, `model_unavailable`, `timeout`, прочее) тоже приходят на языке хода.
- Сутки (`daily`, `pack_daily`) снимаются в 05:00 по Ташкенту. Если отказ пришёлся на 00:00–05:00 по Ташкенту (`retryAfterSec` ≤ 5 ч), текст говорит «сегодня с 05:00» / «Bugun soat 05:00 dan», иначе «завтра с 05:00» / «Ertaga soat 05:00 dan».
- Старый UI понимает `hourly`, `daily` и `monthly`; `pack_daily`, `busy` и `ip` он показывает как часовой лимит. Карточку по новым полям делает WP-06.
- Гостевой `GET /api/gpt/account` отдаёт `freeLimits: {daily, hourly}` из конфига и в D1 не ходит. Вошедшему `remaining` считается по аккаунту и по IP, как в чате.

## Счётчик упоров `gpt_limit_hits` (migrations/0066)

Каждый 429 в фоне добавляет 1 в строку `(org_id, day, reason, subject)`, где `day` — UTC-день `YYYY-MM-DD`. `subject` — тот же псевдоним, что у квоты: `acct_…` или хеш IP гостя. Ни адреса, ни текста там нет. Строки старше 93 дней удаляет крон обслуживания. Перекей хешей при вводе соли (WP-07) включает `gpt_limit_hits.subject`.

## Проверка после релиза R1

1. Со своего адреса отправить в чат 6 сообщений подряд. Если на проде включён Turnstile, отправлять через Browser pane, иначе можно `curl`. 6-й ответ: HTTP 429, `reason: "hourly"`, `retryAfterSec` ≤ 3600, заголовок `Retry-After`. Пять ответов тратят пять ходов `:free`.
2. Агрегат (только чтение):
   ```sql
   SELECT day, reason, tier, COUNT(*) AS subjects, SUM(n) AS hits
   FROM gpt_limit_hits WHERE org_id='gptbot-consumer' AND day>=date('now','-1 day')
   GROUP BY day, reason, tier ORDER BY day, reason;
   ```
   После шага 1 `hourly/free` вырос хотя бы на 1.
