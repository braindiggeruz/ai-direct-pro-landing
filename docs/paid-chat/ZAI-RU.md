# Z.ai в AI-чате: как включить, выключить и что делать при сбоях

*Пакет B платного AI-чата, 2026-09-30. Код: `functions/lib/gpt-chat/model-provider.ts`, `zai-chat.ts`, `model-pricing.ts`, `operator-alert.ts`. Тесты: `tests/gpt-zai-provider.test.ts`, `tests/gpt-model-policy.test.ts` (третий переключатель, WP-03).*

## Коротко

- Z.ai (модели GLM компании Zhipu) подключён к веб-чату как **второй** провайдер. OpenRouter остаётся запасным: Z.ai занимает не больше одного места из трёх в цепочке моделей.
- **Сейчас включено (с 2026-10-03, по решению владельца).** Ключ прислал владелец; секрет `ZAI_API_KEY` задан, копия — только в `C:/Users/Borinio/.config/gptbot-private/zai-api-key.txt`. Оба уровня отвечают `zai/glm-4.7-flash`, запасная цепочка OpenRouter прежняя. Платные модели Z.ai пока недоступны: на аккаунте нет баланса (`glm-4.5-air` и `glm-4.7-flashx` отвечают 1113). После пополнения — `ZAI_MODEL_PAID = "glm-4.5-air"` в двух местах и деплой. Проверка качества и её ограничения — `docs/paid-chat/eval/zai-check-2026-10-03-free.md`: русский хороший, узбекский заметно слабее (фактические ошибки).
- Z.ai включается, только когда выполнены **все три** условия (решение L10 плана):
  1. `GPT_MODEL_PROVIDER = "zai"` в `wrangler.toml`, после чего сделан деплой;
  2. `GPT_ZAI_EVAL_APPROVED = "<ГГГГ-ММ-ДД>"` — дата слепой пробы, по которой Z.ai одобрен; к ней в репозитории лежит отчёт `docs/paid-chat/evals/zai-<дата>.json`, иначе тесты падают;
  3. в Cloudflare Pages задан секрет `ZAI_API_KEY`.
- Бот Javob (@gptbot_javob_bot) и бот @gptbotuz_bot остаются на OpenRouter в любом случае.
- Под ответом чат пишет модель, которая действительно ответила, например `zai/glm-4.7-flash`. Чат никогда не называет себя ChatGPT.

## Как включить

1. **Аккаунт.** Зарегистрируйте на https://z.ai аккаунт с **оплатой по факту** (pay-as-you-go) и пополните баланс небольшой суммой (гипотеза: $10). Предоплаченный баланс не возвращается.
   - **Тариф GLM Coding Plan для сайта использовать нельзя.** По правилам Z.ai он разрешён только в поддерживаемых инструментах для программирования, а за другое использование блокируют аккаунт.
2. **Лимиты.** Посмотрите лимиты аккаунта в кабинете: https://z.ai/manage-apikey/rate-limits. По сторонним данным, бесплатная GLM-4.7-Flash держит примерно 1 запрос одновременно.
3. **Ключ.** Создайте API-ключ. **Не присылайте его в чат и не записывайте в файлы.** Введите его сами как секрет:
   - Cloudflare → Workers & Pages → `ai-direct-pro-landing` → Settings → Variables and Secrets → Production → Add → тип **Secret**, имя `ZAI_API_KEY`;
   - или в терминале: `npx wrangler pages secret put ZAI_API_KEY --project-name ai-direct-pro-landing` (команда сама попросит значение).
4. **Слепая проба.** До переключения прогоните пробу качества (раздел «Слепая проба» ниже) и решите: Z.ai или оставить как есть. Оставить как есть — тоже нормальный итог.
5. **Отчёт.** Если Z.ai одобрен, положите в репозиторий `docs/paid-chat/evals/zai-<дата>.json` (формат — в разделе «Слепая проба»).
6. **Переключатели.** В `wrangler.toml` поменяйте **в двух местах**, иначе тест упадёт:
   - `GPT_MODEL_PROVIDER` с `"openrouter"` на `"zai"`;
   - `GPT_ZAI_EVAL_APPROVED` с `""` на ту же дату, что в имени отчёта.

   Два места — это длинная строка `GPTBOT_RUNTIME_CONFIG_JSON` (`"GPT_MODEL_PROVIDER":"zai"`) и таблица `[vars.GPTBOT_RUNTIME_CONFIG]` внизу файла (`GPT_MODEL_PROVIDER = "zai"`).
7. Проверьте (`node --import tsx --test tests/runtime-config.test.ts`, `tests/gpt-zai-provider.test.ts` и `tests/gpt-model-policy.test.ts`) и сделайте деплой.
8. **Проверка на сайте.** Задайте вопрос в чате. Под ответом должна появиться подпись `zai/glm-4.7-flash`. Если там модель OpenRouter, значит Z.ai не ответил и сработал запасной вариант (причина — в разделе «Где смотреть»).

## Как выключить

- **Обычный способ.** Верните `GPT_MODEL_PROVIDER = "openrouter"` в обоих местах `wrangler.toml` и сделайте деплой. Можно также удалить секрет `ZAI_API_KEY`, но изменения переменных Pages вступают в силу только с новым деплоем.
- **Срочно, без деплоя.** Заблокируйте все модели Z.ai в таблице здоровья моделей. Чат перестанет вызывать Z.ai со следующего сообщения, а OpenRouter продолжит отвечать:

  ```sql
  -- npx wrangler d1 execute gptbot-ai-drafts --remote --command "<этот SQL>"
  INSERT INTO gpt_model_health(org_id, model, blocked_until, code)
  VALUES ('gptbot-consumer', 'zai/*', 4102444800000, 'manual_off')
  ON CONFLICT(org_id, model) DO UPDATE SET blocked_until = excluded.blocked_until, code = excluded.code;
  ```

  Чтобы снять блокировку: `DELETE FROM gpt_model_health WHERE org_id='gptbot-consumer' AND model='zai/*';`

## Настройки

Все настройки, кроме ключа, публичные и лежат в `wrangler.toml` в двух местах с одинаковыми значениями.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ZAI_API_KEY` | — (секрет) | Ключ Z.ai. Только секрет Cloudflare, никогда не в `wrangler.toml`. |
| `GPT_MODEL_PROVIDER` | `openrouter` | `zai` ставит одну модель Z.ai первой. Любое другое значение означает OpenRouter. |
| `GPT_ZAI_EVAL_APPROVED` | пусто | Дата одобрившей слепой пробы, `ГГГГ-ММ-ДД`. Пусто, несуществующая дата или другой формат — Z.ai выключен. |
| `ZAI_MODEL_FREE` | `glm-4.7-flash` | Модель для бесплатного уровня. Разрешены только бесплатные: `glm-4.7-flash`, `glm-4.5-flash`. |
| `ZAI_MODEL_PAID` | `glm-4.5-air` | Модель для платного уровня. Разрешены `glm-4.7-flashx`, `glm-4.5-air`, `glm-4.7-flash`, `glm-4.5-flash`. |
| `ZAI_TIERS` | `free,paid` | Для каких уровней включён Z.ai. Например, `paid` — только для платного. Пусто или ошибка — ни для какого. |
| `ZAI_TIMEOUT_MS` | `12000` | Сколько ждать Z.ai: в потоке — до первого слова, без потока — весь ответ. Допустимо от 3000 до 15000. |

Если модель не из разрешённого списка (например, `glm-5.3`), чат её не использует, работает на OpenRouter и один раз пишет в лог `gpt_zai_model_rejected`.

**GLM-5.x не брать:** у них нельзя отключить «размышление», первое слово появляется через 9–12 секунд, а лимит ожидания — 12 секунд.

## Что значат ошибки Z.ai и что делает чат

Источник: https://docs.z.ai/api-reference/api-code (прочитано 2026-09-30).

| Код Z.ai | Что случилось | Что делает чат |
|---|---|---|
| **1113** (HTTP 429) | Закончился баланс | Блокирует все модели Z.ai (`zai/*`) на 15 минут и отвечает через OpenRouter. Владелец получает сообщение в Telegram: «Z.ai — закончился баланс» (не чаще раза в час). **Пополните баланс.** |
| **1301** (HTTP 400) | Z.ai отказался отвечать на этот вопрос по правилам безопасности | Модель **не блокируется**: отказ касается одного вопроса, иначе любой посетитель мог бы отключить модель для всех. Вопрос уходит в OpenRouter. Если ответ уже начался, он показывается как частичный. |
| **1302** (HTTP 429) | Слишком много запросов | Блокирует только эту модель на 60 секунд и отвечает через OpenRouter. То же для 1303, 1305 (перегрузка) и 1308–1321 (лимиты использования). |
| 1000–1005, 1220, HTTP 401/403 | Ключ не принят или нет доступа | Блокирует `zai/*` на 10 минут. Владелец получает сообщение «Z.ai — ключ отклонён». **Проверьте ключ.** OpenRouter продолжает отвечать. |
| 1211, 1212, 1221, 1222 | Модель неизвестна или отключена | Блокирует модель на 1 час. Проверьте `ZAI_MODEL_FREE` / `ZAI_MODEL_PAID`. |
| 1210, 1213–1215, 1261 | Ошибка в запросе (например, 1261 — слишком длинный текст) | Модель не блокируется, вопрос уходит в OpenRouter. |
| 1200, 1230, 1234, HTTP 5xx | Сбой у Z.ai | Блокирует модель на 30 секунд. |
| нет ответа за `ZAI_TIMEOUT_MS` | Таймаут | Блокирует модель на 30 секунд и переходит к OpenRouter. |

Текст ошибки от Z.ai (`error.message`) может повторять вопрос пользователя, поэтому он не попадает ни в логи, ни в базу. Сохраняется только код.

Ошибки ключа или баланса Z.ai не блокируют OpenRouter, и наоборот: у каждого провайдера своя блокировка (`*` — OpenRouter, `zai/*` — Z.ai).

## Где смотреть

```sql
-- Какие модели отвечали за последние 7 дней и сколько это стоило
SELECT model_used, COUNT(*) AS answers, ROUND(SUM(cost_usd), 4) AS usd
FROM gpt_messages
WHERE role = 'assistant' AND created_at >= datetime('now', '-7 days')
GROUP BY model_used ORDER BY answers DESC;

-- Что сейчас заблокировано
SELECT model, code, datetime(blocked_until / 1000, 'unixepoch') AS until
FROM gpt_model_health
WHERE org_id = 'gptbot-consumer' AND blocked_until > strftime('%s', 'now') * 1000;

-- Алерты Z.ai
SELECT code, datetime(created_at / 1000, 'unixepoch') AS at
FROM gpt_service_alerts WHERE code LIKE 'zai_%' ORDER BY created_at DESC LIMIT 20;
```

Если среди ответов много моделей OpenRouter при включённом Z.ai, значит бесплатная Flash-модель часто упирается в лимит одновременных запросов. В этом случае стоит оставить Z.ai только для платного уровня (`ZAI_TIERS = "paid"`).

Сообщения владельцу в Telegram приходят через тот же бот и чат, что и заявки: `GPT_NOTIFY_BOT_TOKEN` / `GPT_NOTIFY_CHAT_ID`, а если их нет — `TELEGRAM_ASSISTANT_BOT_TOKEN` / `TELEGRAM_ADMIN_CHAT_ID`. Они не расходуют лимит уведомлений о заявках. Алерты Z.ai идут общим путём срочных алертов, в любом режиме оплаты, с общим потолком `GPT_ALERTS_MAX_PER_HOUR` и выключателем `GPT_ALERTS_ENABLED` (docs/paid-chat/ALERTS-RU.md).

## Слепая проба

Скрипт `scripts/zai-blind-eval.ts` задаёт 20 вопросов (10 на узбекском латиницей, 10 на русском) двум моделям с рабочим системным промптом чата. Какая модель — «A», а какая — «B», скрипт выбирает случайно.

```
node --import tsx scripts/zai-blind-eval.ts --dry-run        # проверка без сети
node --import tsx scripts/zai-blind-eval.ts                  # бесплатный уровень: zai/glm-4.7-flash против бесплатной модели OpenRouter
node --import tsx scripts/zai-blind-eval.ts --paid           # платный: zai/glm-4.5-air против платной основной модели чата
node --import tsx scripts/zai-blind-eval.ts --baseline=nvidia/nemotron-3-super-120b-a12b:free
```

Ключи `ZAI_API_KEY` и `OPENROUTER_API_KEY` задайте только для этой команды. Скрипт их не печатает и не сохраняет. Без ключей он ничего не вызывает и объясняет, что нужно.

Результат — лист оценки `docs/paid-chat/eval/zai-blind-eval-<дата>-<уровень>.md` с пустыми колонками 1–5 (правильность, язык, польза) и отдельный файл-ключ `…-key.json`. Откройте ключ только после того, как выставите все оценки. Лимит ответа и платная модель для сравнения берутся из рабочей конфигурации чата (`GPT_MAX_OUTPUT_TOKENS`, `OPENROUTER_MODEL_PAID`).

**Отчёт о решении** — `docs/paid-chat/evals/zai-<дата>.json`. Его проверяет `tests/gpt-model-policy.test.ts`, когда `GPT_ZAI_EVAL_APPROVED` не пуст:

```json
{
  "date": "2026-10-05",
  "decision": "approved",
  "sheets": ["docs/paid-chat/eval/zai-blind-eval-2026-10-05-free.md"],
  "summary": "по заполненным листам: суммы A/B по правильности, языку и пользе; кто оценивал"
}
```

`date` совпадает с датой в имени файла и в `GPT_ZAI_EVAL_APPROVED`, `decision` равен `approved`, а каждый лист из `sheets` лежит в репозитории.

## Риски и оговорки

- **Юридический вопрос.** Договор заключается с сингапурской компанией Z.ai. По её политике Z.ai не хранит данные API и не обучается на них. Но данные могут передаваться другим компаниям группы Zhipu, а Zhipu с 16.01.2025 находится в американском Entity List. Поэтому банк может отклонить оплату картой. Этот вопрос и согласие на передачу данных за рубеж (ст. 15 ЗРУ-547) нужно обсудить с юристом **до** включения.
- **Не проверено вживую:** качество узбекского у GLM, реальные лимиты аккаунта, пройдёт ли оплата узбекской картой. Это покажут слепая проба и первая неделя работы.
- **Один баланс на всех.** Когда баланс заканчивается, платные ответы идут через OpenRouter, пока вы не пополните баланс. Для этого и нужен алерт.
