## Почему контактов мало (главные причины, подтверждённые)

1. **Production живёт на старой версии очередей.** Automation Worker деплоился 29.08 и **не содержит** локальных фиксов `4c01c56`: бюджетно-припаркованные задачи замораживают пополнение пула, а одноразовый сбой сайта компании делает её навсегда «мёртвой» в поиске. Это сегодня главный источник «поиск висит / компаний нет».
2. **Задача проверки контакта после падения не возрождается** (QR-1): после dead-letter компания молча выпадает из воронки — её уже не обработать без ручного вмешательства.
3. **Вся добыча публичных контактов (каталоги, t.me) зависит от Firecrawl-search** (DS-1): Jina — только скачивание уже найденной страницы. Исчерпан внутренний бюджет поиска → выход ноль при исправном коде.
4. **Цель «N проверенных контактов» достижима только через собственный сайт компании** (DS-2): Telegram-username из каталога даже после успешной Bridge-проверки не считается («не доказано, что это аккаунт компании»). Это сознательная строгость — но сейчас у неё нет ручного пути, поэтому честный yield занижен.
5. **Подтверждение живёт сутки** (TG-1): verified-набор ежедневно обнуляется без пере-проверки — «вчера были подтверждённые, сегодня пропали».
6. Структурный потолок: у части компаний нет сайта/мобильного/Telegram — воронка обязана показывать честный знаменатель, а не «50 карточек».

## Что мешает отправке

- Главный блокер — не код отправки, а пустое строгое множество: без Bridge-verified контактов кампания корректно не запускается. Причины пустоты — пункты 1-5 выше.
- Из дефектов кода отправки: lease 120 с короче бюджета запроса 125 с (редкий ложный «ambiguous» + пауза кампании), неполная реконсиляция пары sent/effect, лимит длины по code points вместо UTF-16, потеря текста черновика при reload.

## Что уже исправлено (и где)

- Задеплоено: строгий отбор Bridge-verified (`a044cf0`), единый счётчик verified, асинхронная проверка media, редактирование текста при недоступном сервере, preflight/approval с дайджестами.
- **Только локально, не в production**: `4c01c56` (заморозка пула + backoff), `0ddce6c` (Jina fallback).

## Что невозможно проверить без тебя

- Живые D1-агрегаты воронки/очередей и история кампаний (нужна авторизованная сессия или согласие на read-only запросы).
- Реальное состояние Telegram-сессии Bridge (heartbeat/карточка аккаунта).
- Одна согласованная контрольная отправка живому получателю (первая настоящая приёмка сквозного пути).
