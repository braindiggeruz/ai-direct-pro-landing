## Решения и деньги

После прямого подтверждения владельцем действующей кассы и новых цен включён кандидат Click-only shared. Одна касса, исходный callback `/api/payments/click`, `stu_*` — Studio; прочие ID — чат. Каждая ветка проверяет подпись/режим и точную сумму заказа, права выдаются один раз. Чеки/возвраты используют тот же resolver и fiscal policy чата. Подготовленные callbacks завершаются даже при остановленных новых продажах.
Payme остаётся test и исключён из публичных providers. Во внутреннем GPT_PAYMENT_PROVIDERS оставлены click,payme, чтобы песочница и callbacks продолжали работать. Наличие production keys не активирует публичную оплату.
