# Bormi Admin — матрица достоверности данных

Дата: 2026-08-03. Правило одно: у каждого числа на экране есть таблица, из
которой оно посчитано. Если таблицы нет — числа нет, и на его месте стоит явная
карточка «не измеряется».

| Без описания | `sotuvchi_products.description` | NULL или пустая строка | всё время | COUNT | — | пункт исчезает |

## 2. Что НЕ показывается и почему

| чего нет | почему |
|---|---|
| Выручка, GMV, средний чек | Bormi не считает деньги: `total_minor` есть у заказа, но платежей нет, и сумма заказов — не выручка |
| Конверсия, воронка | нет событий просмотра и клика |
| Просмотры карточки | не собираются |
| Активные пользователи, retention | нет событийной телеметрии; `identities` — это записи, а не активность |
| География спроса | нет location-домена; карта мира из demo-шаблона — ровно то, чего быть не должно |
| Очередь модерации | домена модерации нет. Черновик — это не «на модерации», и выдавать одно за другое нельзя |
| Скорость ответа продавца | считается по `answered_at`, но выборка сейчас — единицы строк, и среднее по ним не значит ничего |
| Номер деплоя, версия service worker, Smart Placement | это свойства проекта Pages; Worker не может их прочитать |
| Поиск и спрос, QuickPost-воронка | события ещё не собираются; раздел появится только вместе с privacy-safe телеметрией |

Каждое из этих мест на экране либо отсутствует, либо занято карточкой `DataGap`
с причиной. Ни одно не занято нулём.

## 3. Fixtures

`apps/bormi-admin/src/lib/fixtures.ts` — только dev. Включается флагом
`VITE_ADMIN_FIXTURES=1` и только при `import.meta.env.DEV`, поэтому в
production-бандле ветка статически недостижима и модуль выпадает. Пока фикстуры
активны, панель показывает плашку `SYNTHETIC — данные вымышлены`.

## 4. Один запрос

Командный центр читает **один** endpoint `GET /api/admin/overview`, внутри —
один `db.batch` из 11 запросов, каждый по индексу или по маленькой таблице.
Экраны «Магазины и доступы» и «Аудит» переиспользуют уже существующие endpoints
Owner Control Center. Ни одного запроса из браузера в D1.
