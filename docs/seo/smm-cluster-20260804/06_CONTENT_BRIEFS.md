# 06. Content briefs

**Дата:** 2026-08-04. Брифы составлены до написания текста.

Общие ограничения для всех трёх:

- Ответ на главный вопрос страницы — в первых 100–150 словах.
- Запрещённые вступления («В современном мире…», «Сегодня социальные сети…», «Каждый бизнес нуждается…») не используются.
- Автор: Борис Герасимов (существующая авторская страница `/ru/avtor-boris-gerasimov/`, используется как во всех статьях блога).
- `datePublished` = `dateModified` = `2026-08-04`.
- Никаких гарантий результата, позиций, продаж, подписчиков.
- Никаких выдуманных кейсов, клиентов, цен GPTBot.uz.
- Title 45–65 символов, description 120–160 (пороги `RULES` в `src/shared/audit.ts`).
- Схемы: Organization, WebSite, BreadcrumbList, Article, FAQPage. `Offer`/`Review`/`AggregateRating` запрещены.
- Минимум 3 FAQ (`RULES.minFaqBlog`), минимум 3 исходящие внутренние ссылки, минимум 1 из них — на hub.
