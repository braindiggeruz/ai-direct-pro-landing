## Rules

1. **Identical NAP everywhere.** Same name, same spelling, same URL.
2. **No invented phone, address or opening hours.** A blank field beats a false one.
3. **One listing per directory.** Duplicates dilute and look manipulative.
4. Where a directory offers a description field, use the short description above
   rather than writing a new one each time.
5. Do not pay for a "premium placement" before the free listing has been indexed
   and measured.
6. After each listing goes live, add its URL to `sameAs` in
   `content/global/site.json` and redeploy — that is what ties the citation back
   to the entity.
