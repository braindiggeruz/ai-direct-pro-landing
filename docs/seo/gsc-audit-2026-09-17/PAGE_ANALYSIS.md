## Дубли и технический контракт (краул 289 URL)

- Дублей title / H1 / description: 0. Страниц без H1 или description: 0. Страниц с несколькими H1: 0. noindex: 0. Не self-canonical: 0. Все 200.
- Title > 65 символов: 24 (сервисные лендинги с ценой и суффиксом «| GPTBot», до 89 символов). Description > 165: 32 (9 длиннее 200). Google обрежет; на страницах с показами 20–90.
- Слов < 300: 0 (мин. 349 — политика конфиденциальности). Медиана по блогу ~1 000–2 000.
- Изображения без alt: только пиксель Яндекс.Метрики с `alt=""` — не проблема.
- Внутренние ссылки: главная ссылается на все 289 URL (хаб), поэтому «сирот» формально нет; единственная страница, куда ведут ссылки только с главных, — /ru/kak-sdelat-ai-bota-telegram-instagram/.
