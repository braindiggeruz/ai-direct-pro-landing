```

→ idleLoad,30000  idleLoad,32000  idleLoad,34000
curl -s https://gptbot.uz/sitemap.xml | grep -c '<loc>'
```

Причина системная и описана в брифе: **двенадцать worktree, один проект Cloudflare Pages, прямой upload без гейта.** Любой `wrangler pages deploy` из любой директории немедленно становится продом. Побочный эффект инцидента — ложная гипотеза: страница пропала из sitemap не из-за бага в `scripts/generate-sitemap.ts`. Генератор корректен, `dist/sitemap.xml` содержит 259 URL включая статью. Пропала она из-за отката.

Восстановление продакшена — ход №1 роадмапа Фазы 2. Попытка выполнить его в этой сессии заблокирована классификатором прав (см. §7).

## 3. Главная содержательная находка — дефицит CTR это несовпадение интента, а не плохие сниппеты

Разброс CTR на позициях 3–8 — от **0 % до 14 %**. Позиция не объясняет ничего. Объясняет тип запроса.

**Здоровая группа** — запрос информационный, статья и есть пункт назначения:

| Страница | Показы | Позиция | CTR |
| --- | ---: | ---: | ---: |
| `/ru/blog/kak-oplatit-chatgpt-v-uzbekistane/` | 135 | 3.49 | **14.07 %** |
| `/ru/blog/chatgpt-i-claude-v-uzbekistane/` | 437 | 4.30 | **7.55 %** |
| `/uz/blog/chatgpt-uzbek-tilida-promptlar/` | 93 | 5.82 | **4.30 %** |
| `/` | 74 | 12.85 | **13.51 %** (брендовый) |

**Дефицитная группа** — запрос навигационно-транзакционный, пользователь хочет **сам ChatGPT**, а не текст о нём:

| Страница | Показы | Позиция | CTR | Что ищет пользователь |
| --- | ---: | ---: | ---: | --- |
| `/uz/blog/chatgpt-telefon-va-kompyuterga-yuklab-olish/` | **4 575** | 7.79 | **0.81 %** | скачать приложение |
| `/uz/gpt-uzbek-tilida/` | 931 | 7.12 | **1.50 %** | сам чат на узбекском |
| `/ru/gpt-chat/` | 857 | 5.89 | **2.45 %** | сам чат |
| `/ru/gpt-vs-chatgpt-sravnenie/` | 443 | 7.24 | **0.23 %** | выбрать и пойти пользоваться |
| `/uz/blog/chatgpt-ozbekistonda-vpnsiz-ishlaydimi/` | 176 | 7.65 | **0 %** | рабочий доступ без VPN |

В этих SERP первые позиции держат `openai.com`, магазины приложений и сам продукт. GPTBot.uz стоит седьмым-восьмым **ниже того, ради чего пользователь пришёл**. Переписывание title и description этого не меняет — это не проблема формулировки, это проблема позиции относительно объекта интента.

**Практическое следствие.** 4 575 показов на одной узбекской странице — крупнейший актив сайта по видимости, и он конвертируется в 37 кликов. Ход, который здесь работает, — не сниппет, а дать на странице то, ради чего пришли: рабочий вход в чат выше первого экрана. Ход, который не работает, — ещё раз переписать заголовок.

⚠️ `/uz/gpt-uzbek-tilida/` — **не трогать до 2026-09-22**, идёт замер релиза.

## 6. Открытые вопросы владельцу

1. **GA4 `customDimensionCount: 0`.** Шесть коммерческих параметров (`locale`, `page_kind`, `service_slug`, `cta_zone`, `target_url`, `contact_kind`) отправляются и не читаются ни в одном отчёте. Регистрация не ретроактивна — каждый день промедления теряется навсегда. 20 минут в интерфейсе GA4 540129731.
2. **Яндекс.Метрика 111312750 — свидетель недоступен.** На машине нет ни одного токена Метрики: `F:\Claude\.env` пуст по этой строке. Третий независимый свидетель Фазы 0 заменён на headless Chromium против живого прода.
3. **Cloudflare Web Analytics — свидетель недоступен.** Токен из `F:\Claude\cf-token.txt` имеет только `Pages:Edit`: `rum/site_info/list` → `{"code": 10000, "message": "Authentication error"}`, GraphQL → `authorization denied`, `/zones` → пусто.
4. **engagementRate 0.04 за 2026-08-25.** Property-wide по всем каналам (Organic 1/25, Direct 0/8, Referral 0/3, Cross-network 0/1, Unassigned 0/28), при скачке Unassigned с 2 до 28 сессий. Подпись необработанного дня, не регрессии: деплой 25.08 был в 21:14 по Ташкенту и не мог повлиять на весь день. **Перепроверить после 2026-08-27.**
