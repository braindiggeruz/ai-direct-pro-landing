## Почему сегодняшний срез остался неизвестен

При попытке раскрыть выбор даты именно в карточке сессионных каналов Chrome остановил автоматизацию из-за открытого интерфейса другого расширения. Выбор «сегодня» не выполнен. Защита не обходилась, расширения не отключались, повторные клики и запросы к закрытым внутренним API не делались.

Таким образом, доступ к самой сводке восстановлен и её исторические значения прочитаны независимо от OpenSEO. **Число Cross-network за 08.10, сегодняшние новые пользователи по first-user channels и сравнение по одинаковому часовому cutoff этим чтением не установлены.** Не подтверждены ни фактическая потеря 178 посетителей, ни происхождение прежнего трафика из рекламы, ни уже состоявшееся восстановление атрибуции после правки.

Предположение об остановке рекламы не используется. Появление `composer / (not set)` в живом интерфейсе дополнительно подтверждает существование внутренних UI-меток в атрибуционных измерениях; механизм и пределы исправления описаны в основном диагнозе. Для окончательного ответа остаётся сопоставить одинаковые first-user/session измерения за 07–08.10 после обработки данных и получить сегодняшний почасовой срез, когда интерфейс снова разрешит чтение.
