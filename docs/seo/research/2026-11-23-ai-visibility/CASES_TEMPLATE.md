# Шаблон кейса GPTBot.uz — что нужно от владельца (23.11.2026)

ТЗ, волна 3, п. 8: «Формат кейсов с цифрами… Факты и цифры запроси у владельца, сам не придумывай. Пока фактов нет — только шаблон».

Владелец назвал клиентов (ответ на шаг 0, 23.11.2026): **cakecity.uz, mirac.uz, deutschexrepte.com, bekcorp.uz**. Задач, результатов и сроков пока нет, поэтому страницы кейсов не публикуются: кейс без проверяемых фактов — тонкая страница и риск выдуманных цифр. Образец уже опубликованного кейса: `/ru/blog/keys-cake-city-platforma-kondirterskoy/`.

## Что прислать по каждому клиенту

| Поле | Пример формулировки | Обязательно |
|---|---|---|
| Клиент и сфера | «Cake City — кондитерская, Ташкент» | да |
| Разрешение назвать клиента | «согласовано с … (дата)» | да |
| Задача клиента своими словами | «заявки терялись в Instagram и Telegram» | да |
| Что сделали | сайт / каталог / Telegram-бот / CRM / SEO | да |
| Каналы и интеграции | Telegram, Instagram, сайт; AmoCRM, Bitrix24, Payme | да |
| Срок проекта | «с 03.2026 по 05.2026» | да |
| Цифры «до» и «после» | только измеренные: заявки в неделю, время ответа, доля заявок из бота | если есть |
| Источник цифр | CRM, Google Analytics, Search Console, отчёт бота | да, если есть цифры |
| Период измерения | «4 недели до и 4 недели после запуска» | да, если есть цифры |
| Цитата клиента | дословно, с именем и должностью, с разрешением | нет |
| Скриншоты | без персональных данных клиентов | нет |

## Как будет выглядеть страница (после фактов)

1. **Коротко** — одна-две фразы с главной цифрой и периодом («за 4 недели после запуска … по данным CRM»).
2. **Задача** — слова клиента.
3. **Что сделали** — список работ и каналов.
4. **Результат** — таблица «до / после» с источником и периодом; если цифр нет, раздела нет.
5. **Что не сработало или ограничения** — честно.
6. **Сроки и состав работ** — без цены проекта, если клиент не разрешил.
7. **FAQ** и ссылки на страницу услуги.

## Чего не будет

- Цифр без источника и периода, округлений «примерно ×2», «в разы».
- Отзывов и рейтингов без согласия клиента; разметки Review/AggregateRating.
- Логотипов и названий клиентов без разрешения.

Когда факты будут, кейсы выпускаются отдельным PR (RU и UZ), со ссылками со страниц услуг и записью в CHANGE_LOG.
