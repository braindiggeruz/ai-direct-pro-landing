### 6.1 Какие корзины несут показы и чего хотят люди

- **RU-чат** живёт на навигационных запросах людей, которые ищут сам ChatGPT и пишут его по-разному: семья искажений —
  76,4 % показов top-60 за 28 дней при CTR 0,155 %; «чачи пити» один — 33 732 показа (35,9 % страницы), CTR 0,06 %, только
  16,8 % из них из Узбекистана. Кликают модификаторы, а не голый бренд: «чат gpt онлайн без регистрации» 3,70 % на поз. 9,0,
  «чати пити онлайн» 1,30 %, «chatgpt uzbekcha скачать» 1,13 %, «chatgpt bepul» 0,74 %.
- **UZ-чат** живёт на «chatgpt kirish» (53,0 % показов, CTR 0,40 %), где вся первая десятка — официальные страницы входа
  ChatGPT: интент — попасть в свой аккаунт ChatGPT, мы на ~7-й позиции этому не отвечаем. Самая кликабельная корзина —
  язык («chatgpt uzbekcha» 1,62–2,21 %, «chatgpt kirish uzbek tilida» 1,04–1,06 %), но после 05.10 она почти исчезла из
  показов страницы.

### 6.2 Почему упал CTR — три гипотезы по отдельности

1. **R-S1 (title + тело, 05.10)** — сильная гипотеза для обеих страниц, но механизмы разные.
   - RU: показы в день 1 196 (01–04.10) → 6 513 (05–07.10); показы вне Узбекистана 421 за 4 дня → 12 419 за 3 дня;
     «чачи пити» 0 → 8 209 за 3 дня. По времени совпадает с тем, что R-S1 убрал «в Узбекистане» из title и тела и добавил в
     тело «чачи/чати пити», «джипити». Клики в день при этом выросли: 8,8 → 14,7 → 10,7. Падение CTR RU-чата — в основном
     рост знаменателя. Но и внутри Узбекистана CTR упал 0,46 % → 0,31 %, а по сохранившимся запросам: «chatgpt kirish»
     0,38 % → 0,11 %, «chatgpt bepul» 0,97 % → 0,64 % (позиция 5,4 → 6,3).
   - UZ: с 05.10 UZ-чат теряет запросы с «uzbek» (7 988 показов при CTR 1,18 % → 701 при 0,43 %); CTR в Узбекистане
     0,95 % (P2) → 0,59 % (P3). Title Т-Б (06.10) с «o‘zbek tilida» эту корзину не вернул. Одновременно поменялись H1 и
     текст под чатом, так что вклад одного title отделить нельзя.
2. **Description 08.10 («3 бесплатных пробных ответа… затем AI-пакет» / «3 ta bepul sinov javobi, keyin AI paket»)** —
   на RU-чате не видна (0,225 % → 0,245 %; uzb 0,31 % → 0,29 %). На UZ-чате правдоподобна, но не доказана: CTR в
   Узбекистане 0,59 % → 0,40 %, клики в день 23,3 → 10,2, «chatgpt kirish» 0,57 % → 0,36 %. Против: позиция в то же время
   6,57 → 6,91, переобход после 08.10 не подтверждён, а в снимке 24.10 Google показал для RU-чата текст страницы вместо
   meta description. Окно (c) — всего 3 дня.
3. **Состав показов и гео** — для RU-чата главная причина: запросы без искажений 0,61 % → 0,48 %, а доля семьи искажений
   выросла с 8,9 % до 82,2 %; KGZ+KAZ+TJK — 51,6 % показов за 28 дней при CTR 0,10 %. CTR RU-чата только по Узбекистану —
   0,335 %. Для UZ-чата тоже существенна: доля «chatgpt kirish» 44,9 % → 55,2 %, «chatgpt yozish» 280 → 6 178 показов
   (CTR 0,32 %), языковые запросы потеряны.

### 6.3 Требования к новым сниппетам

**Обе страницы**

- Обещать только проверяемое: 3 бесплатных пробных ответа без регистрации (с 08.10 — за всё время, затем AI-пакет),
  работает в браузере без установки, отвечает по-русски и по-узбекски, независимый сервис (не OpenAI и не ChatGPT).
  Оговорку о независимости оставить: она нужна для честности, а не для CTR.
- Не обещать: «бесплатно / bepul» без числа (в title можно, только если «3» стоит в description), «безлимит»,
  «Kunlik limit bilan» (неверно с 08.10), вход в аккаунт ChatGPT («ChatGPT kirish» как официальный вход), названия
  моделей GPT-4/GPT-5 (ответы даёт Z.ai `glm-5.3-flash`: `GPT_MODEL_PROVIDER = "zai"` в `wrangler.toml` ветки,
  запись `CHANGE_LOG_2026-10.md` от 03.10), годы ради свежести.
- Длина: title 50–58 символов (не больше 60), главный ключ — в первых ~40 символах (мобильные — 71 % и 87 % показов);
  description 140–158 символов.
- Не ставить в сниппеты чатов слова «tarjima / перевод»: «chatgpt tarjima» (236 показов, CTR 0,85 % на UZ-чате) и
  «O'zbekcha tarjimon» в выдаче — работа будущей страницы-переводчика; иначе каннибализация.
- Мерить с даты подтверждённого переобхода (URL Inspection), 28 дней; читать отдельно CTR и клики в день в Узбекистане и
  долю каждой корзины.

**RU-чат**

- Решение владельца — какая аудитория цель. Если Узбекистан: вернуть гео-сигнал («Узбекистан») — до R-S1 89,3 % показов
  были из Узбекистана при CTR 0,59 %. Цена: вероятно, уйдёт часть показов KGZ/KAZ/TJK, которые за 28 дней дали 49 кликов
  из 280 (17,5 %). Если весь СНГ: оставить без гео и принять CTR около 0,1 % на этих показах.
- В title — модификаторы, которые кликают: «онлайн», «без регистрации», а не голое «чачи пити» (0,06 % на поз. 7,5 при
  полном доминировании официальных страниц).
- Главное отличие от RU-конкурентов в снимке — «на русском и узбекском»; держать его в первой половине title или в начале
  description.
- Под узбекскоязычные запросы RU-чат не подстраивать: по «chat gpt o‘zbek tilida» Google уже ставит RU-чат с русским
  title вместо UZ-чата.
- Для «скачать» (2 044 показа «chatgpt uzbekcha скачать», CTR 1,13 %) честный ответ — «в браузере, без установки».

**UZ-чат**

- Поставить языковой ключ в начало title: «ChatGPT uzbekcha» / «o‘zbek tilida». В P1–P2 (title «ChatGPT o‘zbek tilida

- Для «chatgpt kirish» (53 % показов) честный крючок — «ro‘yxatsiz / akkauntsiz yozing», не выдавать себя за вход
