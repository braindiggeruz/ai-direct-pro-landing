## 3. Поправки к действию

1. **Правило — точное совпадение.** Нормализация: регистр, `ʻ ' ’ → ‘`, NBSP → пробел, схлопывание пробелов. Подстроку не ловить: она даёт 12 ложных срабатываний на 23 настоящих.
2. **Исключения — H-1, H-2, H-4a.** Ключ исключения: (файл, блок, цель, анкор). В комментарии — ID и дата W3-02 (≈25.11). H-5 и H-4b в список не вносить: точное правило их не видит. Их исправят W2-01 и W3-02 по своим чек-листам.
3. **H-3 исправить в том же коммите, что W1-10.** Если тест придёт раньше W1-10, он упадёт на H-3.
4. **Протухшие исключения должны падать.** Если исключение больше не нарушает правило, тест падает. Тогда W3-02 обязан удалить его из списка, и список не останется мёртвым.
5. **Добавить файл в `package.json` → `scripts.test`.** `npm test` перечисляет файлы явно. Если в `files` нет `package.json`, тест никогда не запустится. Ровно так уже случилось с правилом 60 % (`tests/seo-commercial-coverage.test.ts:1-7`: «had silently never run»).
6. **Источник `mustNotTarget` — не только `pairs`.** `pairs`: 39 пар, 49 URL, 352 фразы. Нужно ещё читать `architectureDecisions[]` с `url`/`counterpart`. Сейчас там одна такая запись — A8: переводчики, 12 фраз, включая «переводчик» и «tarjimon». Сейчас совпадений 0, но ветка переводчика добавит ссылки на эти страницы. Фразы по одному URL объединять из всех пар: `/ru/gpt-chat/` встречается в C23–C38.

## 4. Опциональную часть `doNotLink[]` — отклонить

`F:\Claude\MONEY_ROBOT_GPTBOT_2026\04_TARGET_URLS.csv`: «DO NOT LINK» стоит у 17 URL. У 15 из них написано «DO NOT LINK **externally**» — это политика кампании внешних ссылок (Money Robot). Из оставшихся двух одна — K6 (правило анкора для chat-gpt-na-russkom), её уже покрывает C10 `mustNotTarget`. Ещё одна — решение владельца «cannibalization».

| Проверка | Число | Источник |
|---|---|---|
| Внутренних ссылок на эти 17 URL сейчас | **181** (53 — на `/ru/telegram-bot-dlya-biznesa/`) | `scratchpad/w111_dnl.py` по опубликованным JSON |
| Из них на гайд по входу `/uz/blog/chatgptga-qanday-kirish-mumkin/` | 14 ссылок с 10 страниц | то же |
| Трафик этого гайда, 28 дней (2026-09-24..10-21) | **50 кликов / 11 707 показов, поз. 7,0** | GSC `get_search_console_performance` page, resultId 9f7ae290 |

Если перенести этот список во внутреннюю проверку, будет одно из двух. Либо тест упадёт 181 раз. Либо он подтолкнёт к удалению внутренних ссылок на страницу, которая сейчас приносит клики. Если список переносить в манифест, то под именем вроде `externalLinkPolicy` и без проверки внутренних ссылок.

## 5. Остальное

- **Честность и карта интентов.** Тест только читает `mustNotTarget` и запрещает анкор с фразой, которая отдана другой странице. Это прямое исполнение C10/C23/C30, оно не противоречит ни манифесту, ни политике анкоров.
- **Эффект.** «0 — защита от регресса» — честно. Тест не меняет ни одной страницы, поэтому не может навредить странице, которая сейчас выигрывает.
- **Трудоёмкость S, риск low, protected=false** — верно. `intent-manifest.json` не входит в `scripts/seo-protection.ts` (grep: 0 совпадений). Если часть 4 отклонить, манифест вообще не меняется.
