## 4. Оценка эффекта

Пункт заявляет «≈1–4 = 10–20 % потолка L5: оплата +4…+24, Claude не оценить». Правило бэклога (`backlog.json` → `estimationRules.internalLinks`) — «10–20 % потолка L5 (показы × 3,59 % − клики)». По нему:

| Цель | Расчёт по правилу | Потолок | Новых ссылок | Внутренний PageRank (`W1-04_pr_sim.txt`) |
|---|---|---|---|---|
| Оплата | 745 × 3,59 % − 45 = **−18,3** | ≤ 0 | 1 | +6,2 %, место 210 → 201 |
| Claude | 958 × 3,59 % − 38 = **−3,6** | ≤ 0 | 4 | +36,3 %, место 232 → 171 (медиана сайта — 0,00169, у статьи будет 0,00152) |

Обе цели уже кликаются лучше ячейки позиции 3, поэтому по собственному правилу бэклога ожидание = 0. L5 заменил потолок двумя другими. Обе замены не держатся:

- **«+4» — «chatgpt uzbekistan»** (74 показа × CTR страницы 6,04 %). Владелец этой фразы по C18 (`intent-manifest.json`, commercial) — `/uz/blog/chatgpt-ozbekistonda-vpnsiz-ishlaydimi/`, а не гайд по оплате. Новый анкор «как оплатить ChatGPT Plus…» эту фразу не продвигает.
- **«+24» — топ-3 по голому «chatgpt plus»** (720/мес, `l3-data/kw1_table.txt:94`). У гайда по оплате по этому запросу за 28 дней нет ни одного показа (`75265e6f`). Одна ссылка со страницы с 12 кликами не выведет его в топ-3 за 28 дней. Вероятность ≈0, значит и 10–20 % от этого числа ≈0.
- Всё, что пункт посчитал в цифрах, приходится на оплату. А оплата получает наименьший прирост: одну ссылку и +6 % PageRank. Основной выигрыш получает Claude, и его пункт не оценивает.

**Исправленная оценка: ≈0–1 клика за 28 дней, уверенность низкая.** Ноль — результат правила бэклога. Единица — не расчёт, а допуск на неизмеримый эффект +36 % PageRank статьи про Claude. Ценность пункта — дешёвая гигиена графа: самые кликабельные RU-статьи сейчас почти без ссылок из текста. Рычагом трафика пункт не является.
