**Основание.** Владелец 19.11.2026 попросил написать «1000 уникальных сео статей» под 1000 запросов из Search Console и сразу выложить их. Я отказался и привёл данные из раздела 3. Взамен владелец одобрил два пункта («Ты абсолютно прав родной! приступай !»):
1. развести каннибализацию в ChatGPT-кластере;
2. переписать сниппеты трёх главных страниц.

Этот документ объясняет, почему ни один из пунктов нельзя выкатить сейчас, и даёт план по датам. Страницы, код и прод не менялись. Кредитов OpenSEO потрачено 0: Search Console и URL Inspection бесплатны.

## 3. Почему не 1000 статей

- **Пробелов нет.** У каждого запроса из списка уже есть страница. Новая статья под такой запрос становится конкурентом своей же странице, а 96 % кликов дают три страницы.
- **Это спам по правилам Google.** Страницы под конкретные похожие запросы — doorway abuse. Массовые страницы без пользы для читателя — scaled content abuse. 248 запросов из тысячи — опечатки и разговорные варианты одного и того же. Санкция действует на домен, а не на отдельные страницы.
- **Это не пройдёт гейты репозитория.** `tests/seo-cluster-quality.test.ts` требует «no two URLs claim the same primary intent». `tests/intent-guard.test.ts` ловит почти одинаковые заголовки. `content/seo/demand-policy.json` требует измеренный спрос.

## 4. Почему пункты 1 и 2 не выкатываются сейчас

- **Пункт 2 уже идёт как эксперимент.** Title и description обоих чатов — это наблюдение R15, его читают 21.12.2026 отдельно по языку запроса, с пометкой 18.11 как даты изменения. Hreflang обоих чатов — A14, выкачен 18.11. Гайд скачивания защищён. Переписать сейчас — значит обнулить оба замера: защищённую ревизию можно провести через гейт, но замер она не спасает.
- **Пункт 1 почти целиком лежит на защищённых и наблюдаемых страницах** (раздел 2). Гайд входа `/uz/blog/chatgptga-qanday-kirish-mumkin/` — это R14, наблюдение до 21.12.
- **Отсчёт A14 ещё не начался.** URL Inspection на 19.11 показывает последний обход до выкладки:
  - `/uz/gpt-uzbek-tilida/` — 2026-11-17T22:58:19Z;
  - `/ru/gpt-chat/` — 2026-11-17T16:18:26Z.

  Дни 7, 14 и 28 считаются от более позднего из двух обходов после 18.11.
- **Правило журнала:** одно изменение на URL за окно наблюдения. Страницы из релизов 16.11 и 17.11 (`CHANGE_LOG_2026-11.md`) сейчас в своих окнах.

**Шаги после 21.12, по порядку:**

**a. C23, шаг W3-02.** 301 с `/ru/blog/chat-gpt-online/` на `/ru/gpt-chat/` через `content/seo/redirects.json`.
- Данные: статья всё ещё первая по 72 запросам, которые C23 отдаёт RU-чату (2 447 показов, 15 кликов). Главные из них:
  - «чат gpt онлайн бесплатно» — 788 показов, 10 кликов, позиция 6,5;
  - «чат gpt онлайн» — 761 показ, 0 кликов, позиция 6,1.
- Собственных запросов у статьи нет, а по правилу C23 «301, если своих запросов нет».
- 301 — это изменение и для `/ru/gpt-chat/`, поэтому его нельзя совмещать в одном окне с правкой сниппета RU-чата.

**b. Владелец семьи kirish.** Решается по итогу R14.
- Если после R14 CTR гайда входа по запросам «chatgpt kirish» без уточнений остаётся ниже, чем у UZ-чата, при разнице позиций до 1: гайд уводится в интент «как войти»:
  - его title, H1 и анкоры переходят к «qanday kirish», «ro‘yxatdan o‘tish», «kirish muammolari»;
  - голый «chatgpt kirish» остаётся UZ-чату;
  - правка проходит через защищённую ревизию.
- Если гайд не хуже UZ-чата — оставить обе страницы как есть.

**c. Сниппет RU-чата для разговорных запросов кириллицей.**
- База: 119 567 показов при CTR 0,16 % на позиции 6,8.
- Делается, только если R15 по русским запросам не поднял CTR этой семьи.
- Вариант для следующего теста пишется после чтения R15, а не заранее.

**d. Повторить этот разбор на периоде после чтений.**
- Сейчас 23 запроса на позициях 4–15 с CTR ниже 1 % и от 1 000 показов дают 366 648 показов.
- A14 и R15 меняют именно эти строки, поэтому новые тесты сниппетов планируются по свежим данным.

**Не делаем:**
- статьи под запросы из этого списка — пробелов нет;
- правки 102 слабых запросов — нужен авторитет, а не текст;
- любые правки внутри открытых окон.

## 6. Как повторить

1. `get_search_console_performance`:
   - проект GPTBot.uz, `dimensions: ["query"]`, затем `["query","page"]`;
   - `startDate: 2026-08-16`, `endDate: 2026-11-16`, `type: web`;
   - `rowLimit: 1000`, `startRow` 0 / 1000 / 2000 / 3000, до `hasMore: false`.
2. Отбросить строки, где запрос:
   - совпадает с `ai\d{3,}`;
   - содержит URL;
   - содержит `site:`;
   - длиннее 25 слов;
   - не содержит букв.
3. Топ-1000: клики по убыванию, затем показы по убыванию.
4. Основная страница запроса: больше кликов, затем больше показов среди его пар `query + page`.
5. Защищённые пути: `PROTECTED_PATHS` в `scripts/seo-protection.ts`.
