# Таргетированная реклама: роадмап статей под ответы ИИ и поиск · 23.11.2026

## 1. Коротко

- **Основание.** Владелец 23.11.2026: «собрать максимально запросов по таргетированной рекламе через AnswerThePublic и, если нужно, OpenSEO; роадмап, чтобы написать целую партию статей и забрать максимально все запросы по таргетингу». Таргет — часть рекламного кластера, поэтому действует решение D-ADS-GPT-20261123: спрос в ИИ (D1) считается основанием для информационных статей.
- **Данные.** 26 поисков AnswerThePublic: 18 новых и 8 из роадмапа рекламы. Получено 623 уникальных вопроса к ChatGPT и Gemini о таргете и 864 подсказки Google. OpenSEO: 580 ключей по пяти семенам для Узбекистана. Search Console за 20.08–20.11: 56 строк «запрос × страница» с «таргет / target».
- **Главное.** В Google спрос на таргет по Узбекистану маленький: «таргетинг в инстаграм» — 720 в месяц, «таргет» — 390, остальное не больше 50. Вопросов к ИИ много, и у них есть понятная структура.
- **Узбекская кириллица.** Узбекская статья `/uz/blog/target-reklama-nima/` показывается по «target nima» (156 показов, позиция 6,3). Почти столько же даёт кириллица «таргет нима» (121 показ, позиция 6,4).
- **Уже закрыто страницами сайта:** выбор таргетолога, креативы, запуск Instagram из Узбекистана, окупаемость, язык рекламы, блогеры. Гайд по Meta Ads Manager на узбекском — в волне C2 рекламного роадмапа.
- **Предложение:**
  - 8 новых тем, 14 новых URL на русском и узбекском;
  - быстрые правки трёх существующих страниц без новых URL;
  - тема «профессия таргетолога» (11,4 % вопросов) — на решение владельца.

## 6. Связки и защита

- **Пары в `content/seo/intent-manifest.json`.** Статья не берёт ключи своей денежной страницы:
  - у `/ru/targetirovannaya-reklama-tashkent/` — «таргетированная реклама в ташкенте», «заказать таргет», «услуги таргетолога», «настройка таргетированной рекламы ташкент», «ведение таргетированной рекламы»;
  - у `/uz/instagram-target-yoqish/` — «target yoqish», «instagram target», «target yoqish narxi»;
  - «targetolog» не бывает главным ключом (A7).
- **Факты только из первоисточников с датой:** справка Meta (аудитории, пиксель, лид-формы, правила и блокировки, Ads Manager), lex.uz, опубликованные цены сайта. Цены конкурентов не приводим.
- **Ревизия защиты главной** — для каждого нового URL. У каждой страницы не меньше двух входящих ссылок из существующих статей.
- **Текст:** без слов «официальный / rasmiy / official», без обещаний результата. Узбекская версия пишется по-узбекски, с o‘ / g‘ (U+2018).
